# plover-facility-data

공공데이터 원본 CSV를 정제해 쓰레기통/화장실 위치 조회 API용 DB 데이터를 만들기

## 프로젝트 목적

플로깅(plogging) 앱에서 사용자 주변의 **쓰레기통**과 **공중화장실** 위치를 지도에 표시하고 근처 시설을 조회하는 API의 DB 데이터를 준비한다.

## 원본 데이터

| 파일 | 출처 | 원본 행 수 |
|---|---|---|
| `data/전국휴지통표준데이터.csv` | 공공데이터포털 | 3,358행 |
| `data/공중화장실정보.csv` | 공공데이터포털 | 53,500행 |

- 인코딩: CP949 (EUC-KR)
- 좌표계: WGS84

## 데이터 정제 결과

### 휴지통

| 단계 | 제거 행 수 |
|---|---|
| 중복 제거 (name + 위도 + 경도) | 61행 |
| **최종 행 수** | **3,297행** |

### 화장실

| 단계 | 제거 행 수 | 비고 |
|---|---|---|
| 미개방 제거 | 565행 | 개방시간이 미개방으로 등록된 시설 |
| 임시·이동식 제거 | 2,471행 | 간이화장실·이동화장실 (고정 시설 아님) |
| 좌표 없음 제거 | 23,252행 | 원본의 약 45% |
| 좌표 범위 초과 제거 | 5행 | WGS84 범위 벗어난 이상값 |
| 중복 제거 (name + 위도 + 경도) | 702행 | |
| **최종 행 수** | **26,505행** | |

> 간이화장실·이동화장실은 행사·공사 현장에 임시 배치되는 시설로, 상시 존재하지 않아 제외.

## 출력 파일

### `data/cleaned/cleaned_trash_bins.csv`

| 컬럼 | 설명 |
|---|---|
| `name` | 설치장소명 |
| `road_address` | 도로명주소 (없으면 빈 값) |
| `latitude` | 위도 (WGS84) |
| `longitude` | 경도 (WGS84) |
| `trash_type` | 휴지통 종류 (일반쓰레기 / 재활용쓰레기 / 기타) |

### `data/cleaned/cleaned_toilets.csv`

| 컬럼 | 설명 |
|---|---|
| `name` | 화장실명 |
| `road_address` | 도로명주소 (없으면 빈 값) |
| `latitude` | 위도 (WGS84) |
| `longitude` | 경도 (WGS84) |
| `toilet_type` | 구분 (공중화장실 / 개방화장실) |
| `open_time_type` | 개방시간 유형 (상시 / 정시 / 불규칙) |

## 실행 방법

```bash
pip install pandas
python scripts/clean_facility_data.py
```

## 데이터 한계 및 향후 과제

- **휴지통 데이터 부족**: 전국 3,297개는 공공데이터 등록 기준이라 실제보다 훨씬 적음
- **화장실 좌표 누락**: 원본의 약 45%가 좌표 없음. geocoding 보정 시 활용 가능한 데이터 증가
